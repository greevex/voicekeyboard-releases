# Voice Keyboard для Android — релизы

Готовые APK голосовой клавиатуры Voice Keyboard: плавающая кнопка микрофона поверх любых приложений, диктовка с
голосовыми командами («клава, замени вторник на среду») и перепроверкой текста перед вставкой. Исходники — в
приватном репозитории; сюда их сборку выкладывает компьютер, на котором Voice Keyboard собирается.

**Поставить впервые:** Releases → последний релиз → файл `.apk`; откройте его на телефоне и разрешите установку из
этого источника. Дальше приложение само проверяет этот репозиторий раз в несколько часов и ставит новые версии,
когда вы не диктуете.
